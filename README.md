# Nordic RICE for Shadow-SetUp

A Nord-inspired terminal theme for Termux.

## Features

- Nord color palette (Polar Night + Snow Storm)
- Startup animation in frost blue
- TTS greeting in English
- Custom neofetch config
- `nordic-fetch` command (neofetch wrapper)
- All aliases and functions in English

## Installation

```bash
sw rice install https://github.com/Shadow-TermDev/nordic-rice-termux.git
```

## What's Included

- `manifest.json` — Dependencies + file mappings
- `rice.sh` — Startup animation + TTS
- `setup.sh` — One-time setup
- `aliases.sh` — Shell aliases
- `functions.sh` — Shell functions
- `colors.properties` — Nord color scheme for Termux
- `neofetch.conf` — Neofetch config
- `nordic-fetch` — Custom neofetch wrapper script
- `termux.properties` — Termux settings

## Dependencies

- `neofetch` (auto-installed via manifest)
